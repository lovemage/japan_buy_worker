# 首頁全面改版（現代 SaaS 俐落風） — Design Spec

日期：2026-06-11
狀態：已與業主確認方向

## 目標

重做 `public/index.html` 的視覺與文案，讓台灣賣家（代購、蝦皮/IG 賣家、創作者）第一屏就理解「拍照 → AI 自動辨識上架」的價值並感到「我需要這個」。同時把定價區 CTA 從「聯繫客服開啟方案」接上 PAYUNi 線上付款流程（見同日 payuni-subscription-billing spec）。

## 決策記錄

| 決策 | 結果 |
|---|---|
| 改版幅度 | 視覺＋文案全面重做（業主選擇，放棄手作拼貼風） |
| 視覺方向 | 現代 SaaS 俐落風：淺色底、大字標題、產品畫面為主角、品牌橘做 accent |
| 技術形式 | 維持單檔 HTML、無框架、inline CSS（與現有架構一致），只動 index.html＋新增結果頁 |
| 不可 regress | GA tracking、auth 狀態切換（登入後 CTA 變化）、pricing carousel、FAQ accordion（PRODUCT.md 規範） |

## 文案策略

核心轉變：品牌敘事 → **痛點直擊＋親眼看見魔法**。訴求效率（上架繁瑣、時間有限），不主打手續費。

### 頁面區塊（由上而下）

1. **Nav**：logo、功能、案例、價格、教學資源、登入／免費開店
2. **Hero**
   - 主標：「拍一張照，商品就上架了」
   - 副標：AI 自動辨識商品、寫文案、抓規格、換算匯率定價——60 秒生成可以直接下單的商品頁
   - CTA：「免費開店」（主）＋「看範例店舖」（次）
   - 右側：**AI 上架動畫演示**（純 CSS/JS，無後端）：手機拍照 → 掃描辨識動效（辨識框、商品名/規格逐項浮現）→ 完整商品頁卡片彈出 → loop
   - 信任列：使用人數、上架件數
3. **痛點對比區**（新增，說服核心）
   - 標題：「還在這樣上架商品嗎？」
   - 左欄（手動，灰調）：查商品資料 → 寫文案 → 修圖 → 查匯率算售價 → LINE 一個一個報價（一件 1～2 小時）
   - 右欄（我拍，橘 accent）：拍照 → 60 秒 → AI 全做完
   - 收尾句：「一天上架 30 件，時間還給你自己」
4. **四步驟流程**：拍照上傳 / AI 生成 / 自動導購 / 成交收款（沿用現有文案精修，改俐落卡片）
5. **功能網格**：AI 商品辨識、AI 文案生成、匯率自動定價、LINE 導購分享、訂單自動彙整、商店模板（每格：icon＋一句利益點）
6. **社會證明**：10,000+ 創作者、累計上架件數、平均省下時數；保留範例店舖連結
7. **定價區**：四方案卡（Free/Plus/Pro/Pro+）＋月繳/半年/一年切換 carousel（行為保留）；付費方案 CTA 改「立即開通」→ 未登入導註冊、已登入開期數選擇彈窗 → POST checkout → auto-submit 跳轉 PAYUNi；方案說明彈窗（含手續費說明）保留
8. **FAQ**：accordion 行為保留，內容增「付款方式」（信用卡／ATM 虛擬帳號）、「可以開發票嗎」等金流相關問答，移除「聯繫客服開通」相關描述
9. **Final CTA**＋**Footer**（條款、隱私、教學資源）

## 視覺規範

- 背景：白／極淺灰分區交替；卡片白底細邊框＋柔和陰影
- 字體：標題粗黑體（Noto Sans TC 900/700），拿掉 Zen Maru Gothic 圓體與 Caveat 手寫體
- 色彩：沿用品牌橘（現有 `--orange`）作為 CTA 與重點色；文字主色深灰近黑；移除紙張紋理、膠帶、撕邊 clip-path、旋轉貼紙等拼貼元素
- 產品畫面（dashboard 模擬、商品頁卡片）成為視覺主角，直線排版、不旋轉
- RWD：375 / 390 / 430px 斷點品質與現有同級；hero 動畫在行動版降階為簡化版（避免效能問題）
- `prefers-reduced-motion` 時動畫停用，顯示靜態完成態

## SEO / Meta

- `<title>` 與 og 描述改為痛點導向（含「AI 自動上架」「代購開店」關鍵字，參考 SEO-KEYWORDS.md）
- 保留現有 GA snippet 與事件追蹤點（CTA click events）；結構化資料如現有則保留

## 實作備註

- 只重寫 `public/index.html`；`workers/public/` 為舊副本，不同步維護
- hero 動畫資產以 inline SVG／CSS 為主，避免新增大圖；若需商品示意圖沿用 `/assets/images/` 既有資源
- 登入狀態判斷沿用現頁既有機制（cookie session → 顯示「進入後台」取代「免費開店」）

## 驗收

- 首屏 3 秒內看懂「拍照就能上架」；hero 動畫 loop 順暢
- 定價 carousel、FAQ accordion、auth 切換、GA 全部正常
- Lighthouse mobile 效能不低於現版
- 375px 寬無水平捲動、無重疊

## 不在範圍

- 其他頁面（store/admin/onboarding 等）的改版；部落格/教學資源內容
