# 升級退款政策條款

> 本文件為平台訂閱方案之升級退款政策草案，供產品頁、結帳流程、服務條款與客服作業參考使用。若正式上線，建議再由台灣律師依實際商業模式、金流流程與頁面文案審閱。

## 一、適用範圍

本政策適用於平台內各訂閱方案之升級交易，包括但不限於使用者於既有方案有效期間內，升級至較高等級方案，或加購因升級而立即提供之數位權限、功能、額度或相關線上服務。

## 二、名詞定義

1. 原方案：指使用者升級前所訂購且仍在有效期間內之現行方案。
2. 新方案：指使用者升級後所訂購之較高等級方案。
3. 未使用期間價值：指原方案自升級生效時點起，尚未屆滿期間之剩餘價值，依本政策約定方式計算。
4. 升級差額：指新方案於剩餘期間之應付費用，扣除原方案未使用期間價值後之金額。
5. 立即提供之數位服務：指付款完成後即開通、交付或可供使用之數位內容、線上功能、權限、額度、席次、API 配額、後台模組、報表、匯出功能或其他線上服務。

## 三、升級生效方式

1. 使用者於平台完成升級付款後，新方案原則上立即生效。
2. 原方案自新方案生效時起停止適用，並由新方案取代。
3. 平台得依產品設計提供「下期生效」之升級選項；如使用者選擇下期生效，則本期內不發生升級差額退款或折抵。

## 四、升級費用計算與折抵規則

1. 使用者於原方案有效期間內升級者，平台原則上不退還原方案已使用期間之費用。
2. 原方案剩餘未使用期間之價值，將按比例折抵新方案於相同剩餘期間之應付費用。
3. 使用者應支付之升級差額，依下列公式計算：

   升級差額 = 新方案剩餘期間費用 - 原方案未使用期間價值

4. 若依前項計算結果為零或負數，平台得以：
   - 將差額保留為帳戶餘額、平台點數或下期折抵金
   - 不另行退還現金
   - 或依當時頁面公告之方案規則辦理
5. 平台如因促銷、贈送天數、折扣碼、企業專案價、合作方案或其他活動，致原方案實際支付價格與牌價不同時，未使用期間價值應以使用者實際支付之對價為基礎計算，不以原價計算。

## 五、退款原則

1. 除法律另有規定或本政策另有約定外，升級交易完成後，原方案已使用期間之費用不予退還。
2. 平台對於升級交易，原則上採「剩餘價值折抵」而非「原單全額退款後重新扣款」方式辦理。
3. 升級所涉及之已實際提供、已開通、已使用、已消耗或已不可回復之數位功能、服務、席次、額度、配額、權限或第三方成本，原則上不予退款。
4. 若平台同意退款，退款順序原則如下：
   - 優先退回為平台帳戶餘額、站內點數或下期折抵金
   - 次優先退回原付款方式
   - 平台得視支付通路限制、退款成本、風險控管與作業能力，決定具體退款方式
5. 因活動優惠、贈品、回饋、加贈天數、折價券、推薦獎勵、佣金、通路補貼或其他附帶利益所產生之價值，除法律另有規定外，不列入現金退款範圍。

## 六、七日解除權與數位服務例外告知

1. 使用者透過網際網路進行方案升級者，屬通訊交易。
2. 如升級內容屬於非以有形媒介提供之數位內容，或屬一經提供即為完成之線上服務，且平台已於升級前明確告知，並取得使用者事前同意後始提供者，該等交易得依相關法令主張排除七日無條件解除權之適用。
3. 前項情形下，平台應於升級頁、結帳頁或付款前之確認流程中，以清楚易懂之方式揭露以下資訊：
   - 升級後新方案將立即生效
   - 原方案未使用期間之折抵方式
   - 升級後立即提供之數位功能、權限或服務內容
   - 該交易於符合法令要件時，可能不適用七日無條件解除權
4. 使用者完成勾選同意、點擊確認或其他足以表示同意之行為後，平台始提供相關數位服務。

## 七、可申請退款或調整之情形

有下列情形之一者，使用者得檢附相關資料向平台申請退款、減價、補償、更換方案、延長使用期間或其他合理處理：

1. 平台未依頁面說明提供升級後之主要功能或權限。
2. 升級後因平台系統異常，致使用者於合理期間內無法正常使用主要服務，且經平台確認可歸責於平台。
3. 升級內容與付款頁、方案頁、廣告頁、銷售說明或客服書面承諾顯著不符。
4. 因重複扣款、錯誤扣款、明顯計價錯誤或其他非可歸責於使用者之事由，致使用者受有不利益。
5. 其他依法應予退款或回復原狀之情形。

## 八、不受理或限制退款之情形

除法律另有規定外，有下列情形之一者，平台得不受理全額退款，或僅按未使用部分酌予處理：

1. 升級後相關數位功能、權限、額度、API 配額、匯出權限、第三方訊息量、廣告額度、席次或其他資源已開通、交付或使用。
2. 使用者申請退款之原因，僅為個人主觀感受、臨時需求改變、誤購高階方案，但平台已依頁面說明完整開通服務。
3. 使用者已明確同意立即提供數位服務，且該服務已開始履行或已完成提供。
4. 使用者有違反平台服務條款、濫用退款機制、惡意重複升降級、異常套利、冒用、詐欺或其他違反誠信原則之情形。

## 九、降級與終止

1. 使用者如欲降級至較低等級方案，原則上自下一計費週期生效。
2. 降級原則上不辦理當期差額退款。
3. 使用者終止訂閱或不再續購者，除法令另有規定或平台另有公告外，已支付但已開始提供之當期方案費用原則上不予退還。

## 十、退款申請流程

1. 使用者應於合理期間內，透過平台指定客服信箱、後台工單、聯絡表單或其他平台公告方式提出申請。
2. 申請時應提供足以識別交易之資訊，包括但不限於：
   - 帳號資訊
   - 訂單編號
   - 升級日期
   - 付款證明
   - 申請原因及相關佐證
3. 平台得視個案需要，要求補充資料後再行審核。
4. 平台完成審核後，將以電子郵件、站內通知或其他適當方式告知處理結果。
5. 如需退款，平台將於確認退款成立後，依內部作業流程及支付通路處理時程辦理；實際入帳時間仍依金流、銀行或發卡機構作業為準。

## 十一、證據留存與風險控管

為保障交易雙方權益，平台得留存下列紀錄作為審核依據：

1. 升級頁、定價頁、結帳頁與條款版本
2. 使用者勾選同意、點擊確認之時間與紀錄
3. 方案開通、功能啟用、配額發放、API 啟用或席次建立紀錄
4. 金流交易結果、付款時間、退款時間與退款方式
5. 登入、操作、通知或其他與爭議判斷有關之必要紀錄

## 十二、條款補充與解釋

1. 本政策如有未盡事宜，依平台服務條款、付款頁公告、活動規則及中華民國相關法令辦理。
2. 本政策之解釋，不得排除消費者依法得主張之權利。
3. 如本政策任何約定依法被認定為全部或一部無效，不影響其餘條款之效力。

## 十三、建議前台揭露文案

以下文案可作為升級付款前之揭露與確認示例：

### 升級說明

本次升級完成付款後將立即生效。
原方案未使用期間之剩餘價值，將按比例折抵新方案費用；原方案已使用期間費用不予退還。

### 同意確認

我已了解本次升級為立即提供之數位服務／線上功能開通。
我同意平台於付款完成後立即開通新方案，並已知悉原方案未使用期間將依平台規則折抵；於符合法令要件時，本交易可能不適用七日無條件解除權。
