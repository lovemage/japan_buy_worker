# 簡中市場後續計畫

日期：2026-10-16。依使用者指示，本文件只規劃，不啟動實作或部署。

## 目前範圍

先服務繁中市場，保留繁中官網、現有方案與新台幣結帳。本次不建立 `/zh-hans/`、不加入簡中 hreflang、不做 Accept-Language 或 IP 自動轉址，也不串接新金流。

繁中使用者也包含港澳與海外華人，但網站須如實標明可用的幣別、收款與配送方式。語言可讀不等於當地金流、物流已支援。

## 第一階段：驗證需求與翻譯範圍

- 根據匿名流量、詢問與實際註冊資料，確認簡中使用者的主要所在地與需求，不把所有簡中使用者視為單一市場。
- 整理首頁、about、方案、FAQ、註冊與關鍵錯誤訊息的翻譯清單；建立繁簡用語表。
- 先釐清各市場可使用的支付、配送、客服與資料處理方式，再決定對外承諾。
- 保留現有台灣繁中內容，不直接以字形轉換取代編輯與人工校對。

## 第二階段：語系路由與搜尋

- 繁中維持現有網址，簡中另設 `/zh-hans/`，提供可手動切換的語言連結。
- 每頁使用自己的 canonical；只有真正對等且已發布的頁面才互相加入 `zh-Hant`、`zh-Hans` 與適當的 `x-default`。
- 只有真的有地區差異內容時才增加 `zh-Hant-TW`、`zh-Hant-HK`，不把同一頁複製成假地區版本。
- sitemap 收錄正式發布的語系頁，JSON-LD、OG、HTML lang 與可見內容保持一致。
- 依瀏覽器語言提出切換建議，保留使用者選擇，避免強制轉址影響搜尋與分享。

## 第三階段：產品在地化

- 將來源幣別、售價幣別、匯率方向、四捨五入與報價時間建模，與現行 TWD 訂單相容。
- 參考幣值須標明匯率來源、時間與實際扣款幣別，不能將參考價當成可支付價格。
- 依已確認的目標市場選一個金流服務商，完成商戶資格、退款、通知驗簽、冪等與對帳設計後才串接。
- 檢查 WhatsApp、微信等分享在目標裝置的可用方式，提供複製連結的備援。
- 資料跨境、禁限售與交易條款交由合適的專業人員確認，不以翻譯代替合規審查。

## 啟動與驗收條件

取得後續實作指示後才開始。先發布少量人工校對頁面；檢查語言切換、canonical/hreflang 雙向一致、索引、行動版排版與現有繁中流程回歸。多幣別與新金流獨立驗收，通過測試交易與退款對帳後才開放。
